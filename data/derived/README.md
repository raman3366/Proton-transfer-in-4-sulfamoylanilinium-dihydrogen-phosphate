# Numerical exports

These CSVs are generated by `python3 tools/export_results.py` from authentic stored JSON and QE output files. They are additional views of the records, not recalculated DFT/MD results and not replacements for the source files. Every row gives a source path plus a JSON key or output line. JSON floating-point literals are read as `Decimal`; no values are fitted to the manuscript. Blank cells mean absent/not applicable.

| File | Rows | Meaning / units |
|---|---:|---|
| `proton_scan.csv` | 8 | Both scan chains; energies in Hartree, distances in Å, explicit convergence flags; Table S7 |
| `dielectric_ladder.csv` | 5 | Dielectric constant, geometry and stored total energy; energies at different dielectric constants are **not comparable**; Table S8 |
| `method_comparison.csv` | 15 | Five methods × three fixed geometries; Hartree and stored kcal mol−1 relative to the salt; Table S9 |
| `periodic_profile.csv` | 5 | Stored constrained profile, PBE and hybrid-corrected PBE0 differences; kJ mol−1 per formula unit and meV per cell are separate columns; Table S15 |
| `qe_output_energies.csv` | 49 | Last printed `! total energy` in each raw QE output, in Ry; includes coarse and alternative runs; a `JOB DONE` marker alone does not establish ionic convergence |
| `converged_zinc_model_relaxations.csv` | 2 | Completed X and Rx zinc-model relaxations; Hartree, Å and dimensionless signed volume; Table S40 context |
| `md_run_index.csv` | 13 | Nine primary, two sensitivity and two validation runs; first long opposite-state visit in ps from ligand release, where present |

`periodic_profile.csv` retains source key names: `E_PBE*_kJ_mol_per_fu` denotes an energy **difference relative to salt (i)**, not an absolute energy. The unit cell contains two formula units. Hybrid values are the SSSP PBE difference plus the SG15 PBE0-minus-PBE correction. They are not differences between mismatched absolute energies.

The campaign table's production-only first passage (often 0.01 ns) is not Table S39's release-relative time. The candidate-N2 sensitivity run is MIXED; its first long crystal-like visit is not a conversion. The run index intentionally excludes benchmark/preflight records from primary/validation totals; they remain identified in the external inventory.

The original publication-formatted tables live in [supporting/05_Tables](../../supporting/05_Tables/). Read their Markdown versions for captions, footnotes and qualifications missing from CSV. `tools/check_results.py` independently checks selected raw-to-table relationships; this is stored-data verification, not a simulation.
